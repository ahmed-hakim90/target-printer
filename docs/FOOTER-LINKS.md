# Footer link behavior

- Footer product-category links open the shared product catalog with the matching category selected.
- Other footer items only render as links when the destination exists in the current application.
- Planned destinations remain visible as non-interactive text until their pages are implemented.
- Contact phone numbers, email, the site URL, About Modern Egypt, Spare Parts, and Consumables are active destinations.
- Technical Support is intentionally omitted from the Support list.
